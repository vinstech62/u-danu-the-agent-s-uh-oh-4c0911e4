One word an agent says when it has no idea what to do: **buffering**. Not an
apology, not an error code — just the spinning wheel, out loud. The program
writes that single word to `/output/entry.txt`, deterministically, with no
network, no randomness, and no timestamps.

## Run it

```sh
python3 main.py
```
